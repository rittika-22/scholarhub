🎓 **ScholarHub**

ScholarHub is a scholarship information and management platform designed to help students discover suitable scholarships, check their eligibility, compare opportunities, organize required documents, and track important deadlines.

The platform provides separate interfaces and functionalities for public users, registered students, and administrators.

✨Key Features

🌐 Public
- Home
- Scholarship Search & Filter
- Scholarship Details
- Scholarship Comparison
- Countries
- About
- Login / Register

👨‍🎓 Student
- Student Dashboard
- My Profile
- My Scholarships
- Eligibility Checker
- Readiness Score
- Personalized Roadmap
- Document Checklist
- Deadline Calendar
- Conflict Detector
- Notifications

🛠️ Admin
- Admin Dashboard
- Scholarship Management
- User Management
- Country & University Management
- Source Verification
- Deadline Management
- Analytics

💻 Tech Stack

**Frontend:** HTML, CSS, JavaScript, Bootstrap, React.js  
**Backend:** Node.js, Express.js  
**Database:** MySQL  
**Deployment:** Vercel, Render


🎯 Project Objectives
Provide centralized scholarship information for students
Make scholarship searching easier and more organized
Help students understand scholarship eligibility requirements
Allow students to compare multiple scholarships
Help students identify missing requirements and documents
Support scholarship preparation through personalized guidance
Help students track deadlines and important scholarship activities
Provide administrators with tools to manage scholarship data efficiently

👥 User Roles
**Public User** - Browse, search, filter and compare scholarships
**Student**	- Manage profile, check eligibility, track scholarships,  documents and deadlines
**Admin** - Manage scholarships, users, countries, universities, sources and deadlines
